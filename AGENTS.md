## Independence and privacy

Reuse old implementations only after checking their current assumptions, dependencies, license, and fit to the agreed design.

Keep credentials, original conversations, raw provider payloads, genuine candidate/business data, supplier quotations, spreadsheets, and live request/budget ledgers outside tracked files. `.local/`, `data/`, and `outputs/` are ignored local locations; ignore rules are not a substitute for staged-file review.

Before activating a migrated or newly wired paid integration, reconcile existing in-flight/unknown requests and spending state, including strictly read-only reconciliation against the canonical legacy `budget.sqlite3` ledger. Paid OpenAI HTTP paths remain disabled by default (`enabled: false`) in offline and CI runs; overspend protection is anchored by platform `Auto-recharge OFF` + `$200/month` hard monthly limit paired with local natural-month realized-spend accumulation (`<= $200`), `max_retries = 0` on billable `POST` requests, PII/secret redaction, and blocking `Astra` on paid HTTP API by default (without upfront speculative per-call cent freezes, cross-month timeout lockouts, remote `DELETE` failure lockouts, or home-directory inode lockfiles; prior-month unresolved timeouts auto-archive without locking new months). A new folder or checkout does not reset the budget or authorize another submission. Migration and adapter wiring do not enable scans, schedules, supplier messages, procurement, advertising, or store writes.

Prefer offline validation and standard hosted CI runners. Do not trigger paid provider calls from CI. Use PowerShell 7 on Windows, Node.js 24 ESM for core runtime and tests, and UTF-8 Python execution for auxiliary scripts.
