# 0003: Local Multi-Model Orchestration and Strict Non-Overreach Boundary for `Luna`

Keep all orchestration local inside this Node.js 24 ESM repository (`src/openai/` + local `Codex CLI`) instead of building a separate cloud OpenAI Platform Agent, deploy monthly `$200` API credits on high-ROI local tasks (`1688` search-page offer ranking, bulk lead triage, native-English pain-point/flagship-accessory seed expansion, `1688` detail-page HD spec vision, deep review/Q&A/A+/Reddit pain-point & true return-cause diagnosis via 50%-discount `Batch API`, uncapped web-search patent/compliance pre-screening with on-demand design-patent drawing vs. 1688 photo lookalike checks, and qualifying-card Chinese 1688 inquiry checklists — while rejecting TTS voice briefings, autonomous 1688 messaging, and indiscriminate concept images), and restrict `gpt-6-luna` (`Decision API`) strictly to undisputed hard red lines ("宁可多放，绝不误杀").

## Considered Options

- **Build a cloud-hosted Agent on OpenAI Platform (rejected):** Visual `Agent Builder` sunsets `2026-11-30`, and cloud agents cannot reach local authenticated browsers (1688/Reddit/Pinterest/Etsy), local SellerSprite/SIF/SP-API MCP servers, local Kaiqi tariffs, or SQLite ledgers.
- **Let `gpt-6-luna` filter suspected patent risk, powered/electronic complexity, or reject whole products on 1688 search pages (rejected):** `Luna` has no deep reasoning or patent-search tools and would falsely kill viable niche blue oceans.

## Consequences

- `Luna` may only hard-exclude undisputed statutory `<= 12y` children's items (preserving adult-storage exemptions) and strict date/holiday-dependent disposables (ordinary apparel and generic phone-case/cable leads may be skipped at discovery intake with explicit skip reasons rather than treated as a 5th global hard kill line); all powered, uncertain, or patent-suspect items pass through as `needs_review` to web-enabled `gpt-6.1-terra`.
- On 1688 search pages, `Luna` only ranks and demotes individual mismatched/bare offers to cut wasted clicks and sliders; it never eliminates the candidate product.
- Local subscription `gpt-6.2-astra` (`ultrafast + max`, `$0` API spend) owns both pre-implementation blueprint/workflow audits and post-implementation Standards + Spec dual-axis reviews.
