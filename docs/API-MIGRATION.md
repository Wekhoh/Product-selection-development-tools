## Spending, recovery, and legacy reconciliation guardrails

- **Slimmed natural-month `$200` budget tracking (2026-11-24):** The account policy requires verified platform `Auto-recharge OFF`, a platform hard limit (`<= $200/month`), and read-only legacy `budget.sqlite3` reconciliation before activation. Locally, `src/openai/budget-ledger.mjs` accumulates realized natural-month usage (`<= 20,000` cents) without upfront speculative per-call cent freezes, without cross-month global account lockouts (prior-month unresolved timeouts auto-archive to logs without blocking new months), without remote `DELETE` cleanup failure lockouts, and without hidden home-directory inode lockfiles (`~/.local-selection-openai-ledger-registry.sqlite`). Paid HTTP API continues to block `Astra` by default (`allowAstraApi = false`) and scrubs raw PII/secrets. [Web search](https://developers.openai.com/api/docs/guides/tools-web-search) · [API pricing](https://developers.openai.com/api/docs/pricing)
- **Zero-retry POST & background recovery:** Billable `POST` requests enforce `maxRetries = 0`. Queued background acknowledgments bind the provider ID in SQLite before polling; idempotent `GET`s retry transient failures and resume cleanly after restarts without duplicate `POST`s; cancellation (`POST /v1/responses/{id}/cancel`) remains an explicit operator action. [Background mode](https://developers.openai.com/api/docs/guides/background) · [Cancel a response](https://developers.openai.com/api/reference/resources/responses/methods/cancel)
- **Read-only legacy `budget.sqlite3` reconciliation:** Before enabling live paid API calls (`legacy_reconciled: true`), `inspectLegacyAutopilotBudget` inspects the canonical legacy `budget.sqlite3` strictly read-only (`?immutable=1` or private snapshot, `query_only = ON`, never writing or creating files on the legacy path) and `reconcileLegacySummary` / `openai-reconcile --legacy-budget` transactionally imports monthly carryover reservations while refusing activation if any unresolved/unknown legacy hold exists. Keep `reserved_cents`, `usage_cost_micros`, and `posted_billed_cents` distinct; never record `0` for an unknown outcome.
- **Local credential storage, `$500 -> $200` subscription transition & `Agent Builder` sunset:** Store the active OpenAI project credential strictly in git-ignored `.local/secrets/openai-credentials.json` (never echoed or tracked in Git; key rotation is not required unless compromised). During the November `$500` Pro cycle, verify `Auto-recharge OFF` and check `Billing -> Credit grants` for any month-end expiring credit grant (`Codex CLI` `Astra` uses `service_tier="default"` + `max` reasoning for major/final sign-off reviews and supports `service_tier="ultrafast"` on routine checks while on Pro-500, falling back automatically to `default` after next month's transition to steady-state `$200/month` Pro + `$200` non-rollover API credit cap). Visual `Agent Builder` is intentionally avoided due to its `2026-11-30` sunset.
- **GPT-6.2 HTTP wire & prompt-caching maintenance rules:** For any future `gpt-6.2-*` (`gpt-6.2-sol` rare escalation) `/v1/responses` maintenance, place reusable static instructions inside the first `developer` message of `input` (GPT-6.2 appends top-level `instructions` after `input`, which breaks prefix caching), avoid mid-chain prefix edits or model switches (which drop encrypted reasoning state), omit unsupported `temperature` / `top_p` / `logprobs` and `service_tier: "flex"`, and prefer `prompt_cache_options: { ttl: "30m" }` where supported.
